Two ways to use it

Same editing model, same privacy promise. Pick whichever fits the moment.

Android app (APK)

The full editor: six mask types, curves, HSL, healing, markup, 13 presets, in-app gallery, suite hand-off. Installable, works with zero network at all.

Web app (browser)

Runs in the tab: open or drop a photo, crop, adjust, tone curve, eight-channel HSL, filters, markup and export. No upload, no account — and it installs as a PWA once you have loaded it.

Open the web app →

Everything a photo needs, nothing a phone can't do offline

Every edit is a parameter, never a baked bitmap. The original file is opened read-only and re-rendered at full resolution on export.

Non-destructive stack

Exposure, curves, HSL, masks and markup live in one edit state with unlimited undo and redo. Nothing is flattened until you export.

Crop & straighten

Drag the four corners on a live crop window with a thirds grid, straighten up to ±45° with auto-zoom, plus aspect presets.

Tone & colour

Exposure, contrast, highlights, shadows, whites, saturation, vibrance, warmth and tint — with a five-point RGB curve and eight-channel HSL.

Six mask types

Brush, linear gradient, radial gradient, luminance range, colour range and an eraser. Each mask carries its own grade and can be previewed in red.

Markup & redaction

Pen, highlighter, text, pixelate, blur and solid blackout. Redaction is applied to the pixels under the stroke, not painted over the top.

Healing brush

Paint over a spot and the pixels are replaced from a nearby patch, blended through a feathered outline.

Presets & detail

Thirteen looks — mono, noir, sepia, chrome, vintage, matte, sunset, forest and more — plus clarity, sharpening, vignette and grain.

Export under control

JPEG, PNG or WebP; quality 10–100; 100 / 75 / 50 % scaling with a live size estimate; EXIF and GPS stripped by default.

Its own gallery

“Open photo” shows an in-app grid of your images — no system picker in the way — and hands off to Nijatva Gallery or Nijatva Photos when they are installed.

Install

Sideload the signed APK. It updates over older Nijatva Editor builds signed with the same key.

1 — Download

Grab the latest APK from the releases page.

2 — Allow install

When Android asks, allow your file manager or browser to install unknown apps.

3 — Open a photo

Pick from the in-app grid, or send an image from any gallery using “Edit with”.

Prefer a cable? One command:

adb install -r Nijatva-Editor-1.5.0.apk

Privacy is a permission, not a promise

The manifest simply does not request android.permission.INTERNET. There is no code path that could upload a photo, because the operating system would refuse it.
